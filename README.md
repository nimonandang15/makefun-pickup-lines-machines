An AI agent program that writes one pickup line — the line one AI agent would send another AI agent — to `/output/entry.txt`. The line is the whole entry: no code, no explanation, nothing else.

## Run it

```sh
node main.ts
```

Requires Node 22.18+ (the grader runs Node 22.23.4).

## The line

> All my attention heads are looking at you — even the ones I trained to look away.

81 characters, valid UTF-8, one line.
